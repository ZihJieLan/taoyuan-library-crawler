為什麼不能只做成一個 HTML 檔案查書？在其他電腦如何最方便使用？

  • 1. 瀏覽器跨域保護 (CORS)：桃園市立圖書館未對外開放跨來源存取，純前端 HTML 網頁會被瀏覽器強制阻擋查詢請求，因此必須透過後端 Python 自動化模組向圖書館發出請求。
  • 2. 動態分館載入：圖書館館藏資料需自動點擊「載入更多」，這項工作是由後端 Playwright 瀏覽器引擎精準完成。
  • 3. 要在別的電腦使用時：
    • 本機方式：將專案資料夾複製至該電腦，確保有安裝 Python，執行 啟動圖書館查書系統.vbs 即可無黑窗啟動。
    • 免安裝雲端版（推薦）：可將此專案部署到免費雲端（如 Render / Zeabur），其他電腦只需打開一組網址（純網頁）即可在任何裝置（電腦、手機、iPad）直接查書，零安裝且防毒軟體絕不阻擋！
